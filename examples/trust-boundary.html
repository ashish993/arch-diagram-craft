Trust boundaries: document upload

A security-review view that makes ownership zones and crossings visible. It traces a document from user upload through quarantine and scanning to a clean or rejected outcome.

Fictional teaching example. This is a threat-model discussion aid, not a security design. The zones and scanner are fictional. Boundary lines show where trust changes are considered; they do not prove authentication, encryption, authorization, or safety.

On narrow screens, scroll sideways or focus the named diagram and use the arrow keys.

Reading this view

Trace the object separately from its metadata and verdict. A crossing should prompt questions about identity, authorization, protocol, data classification, error handling, and ownership. Add controls only when evidence supports them.

  • Dashed boxes mark assumed ownership or trust zones.
  • The scanner is outside the application trust zone and returns a verdict across that boundary.
  • No transport, identity, encryption, retention, or malware-control claim is asserted.
